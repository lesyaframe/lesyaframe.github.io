Каркас запроса

SELECT столбцы, выражения AS имя
FROM таблица AS t
JOIN другая d ON d.id = t.id
WHERE условие на строки
GROUP BY поля
HAVING условие на группы
ORDER BY поле DESC
LIMIT 10;

Порядок выполнения: FROM → JOIN → WHERE → GROUP BY → HAVING → окна → SELECT → DISTINCT → ORDER BY → LIMIT

Агрегаты

В SELECT с GROUP BY только поля группировки и агрегаты. Условие на агрегат пишется в HAVING.

JOIN

JOINтолько пары
LEFT JOINвсё слева, справа NULL
FULL JOINвсё из обеих
CROSS JOINкаждая с каждой (сетки)
-- у кого нет пары
FROM customers c
LEFT JOIN orders o ON o.customer_id = c.customer_id
WHERE o.order_id IS NULL

Фильтр по правой таблице при LEFT JOIN пиши в ON. После JOIN «один ко многим» проверяй count(DISTINCT).

Подзапросы, WITH, UNION

WITH t AS (
  SELECT order_id, sum(quantity*price) total
  FROM order_items GROUP BY order_id
)
SELECT * FROM t
WHERE total > (SELECT avg(total) FROM t);
x IN (SELECT …)в списке из запроса
EXISTS (SELECT …)есть хоть одна строка
UNION / UNION ALLдруг под другом (без дублей / с ними)
EXCEPT / INTERSECTразница / пересечение
coalesce(x, 0)NULL заменить на 0
